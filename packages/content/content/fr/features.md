---
list:
  - label: Puis-je planifier sur toutes les plateformes à la fois ?
    content: Oui. Partez d'une publication maître et publiez sur tous les réseaux sélectionnés. Vous pouvez remplacer le texte, les médias, les hashtags ou le premier commentaire par plateforme avant planification.
    value: '1'
  - label: L'IA apprend-elle la voix de ma marque ?
    content: Elle utilise le profil d'entreprise, le playbook et les exemples que vous fournissez. Plus vous ajoutez de contexte, plus les brouillons ressemblent à votre contenu existant.
    value: '2'
  - label: Existe-t-il une application mobile ?
    content: L'application web est responsive et fonctionne depuis le navigateur du téléphone pour les validations et réponses rapides. Aucune application native n'est nécessaire pour planifier.
    value: '3'
  - label: Puis-je importer mon contenu existant ?
    content: Oui. Utilisez l'import CSV pour les publications en masse et importez vos médias actuels dans la bibliothèque partagée avant de commencer.
    value: '4'
  - label: Faut-il l'API pour utiliser le produit ?
    content: Non. L'API, la CLI et le serveur MCP sont des couches d'automatisation optionnelles pour les développeurs et les utilisateurs d'assistants IA. L'interface normale couvre tout le flux.
