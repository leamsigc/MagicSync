::BaseFaq
---
list:
  - label: Was ist MCP?
    content: Model Context Protocol ist ein offener Standard, mit dem ein KI-Client Tools entdecken und aufrufen kann. MagicSync stellt Publishing-, Medien-, Analytik- und Board-Tools unter /mcp bereit.
    value: '1'
  - label: Welche Agenten werden unterstützt?
    content: ChatGPT, Claude, Claude Code, Codex, Cursor, OpenClaw, Hermes Agent, Grok Bot, Grok Build, Muse, Perplexity Computer, nanoclaw, Paperclip, der MCP-Server selbst und die AI Agents CLI.
    value: '2'
  - label: Kann ein Agent ohne Freigabe veröffentlichen?
    content: Nur ein Vollzugriffs-Key kann direkt veröffentlichen. Lese-Keys können nichts erstellen oder planen, und freigabegesteuerte Workflows warten immer auf eine menschliche Entscheidung.
    value: '3'
  - label: Brauche ich die API, wenn ich nur ChatGPT nutze?
    content: Nein. Verbinde dich über MCP mit OAuth oder einem Key. Die REST-API ist da, wenn du Skripte, CI-Jobs oder deine eigene Integration willst.
    value: '4'
  - label: Sind meine Daten sicher?
    content: Tokens und Keys sind pro Arbeitsbereich begrenzt, Anfragen haben Rate-Limits, jeder Aufruf wird auditiert und du kannst einen Key sofort widerrufen.
    value: '5'
  - label: Kostet das extra?
    content: Nein. MCP, API und CLI sind in jedem Plan enthalten. Du zahlst nur dein normales MagicSync-Abo oder hostest kostenlos selbst.
    value: '6'
