# Evidence rubric

Grade every finding before it enters a brief.

| Grade | Test | Allowed use |
|---|---|---|
| Verified | Two independent primary sources agree, or one authoritative source states it directly with data | Can be a headline claim |
| Single-source | One credible source; no corroboration found | Can be a supporting claim; name the source |
| Contested | Credible sources disagree | Present both readings; never pick silently |
| Unknown | No source found | List under unknowns; never assert |

## Source ranking

1. Primary data: official statistics, filings, first-party documentation.
2. First-party reporting: the organization that owns the fact.
3. Secondary reporting: reputable outlets citing a primary source.
4. Aggregators, forums, content farms: signal only, never evidence.

## Red flags

- A number with no methodology or date.
- A quote that cannot be located in the linked page.
- A study summary with no link to the study.
- Recency-critical claims (prices, features, platform rules) with no date.
