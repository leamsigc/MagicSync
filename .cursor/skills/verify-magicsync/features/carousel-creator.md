# Carousel creator

The carousel creator is a public tool at `/tools/carousel-creator`. A visitor with no
account builds a multi-slide carousel in the browser, applies a layout template to
each slide, checks the result in the Instagram, LinkedIn, or all-pages preview, and
exports it. The load, slide creation, navigation, and preview switching were all
observed on 2026-10-04. Template application, palette changes, and export are read
from source and still need a drive.

## Sub-features

- `carousel-open` loads the editor with no session.
- `carousel-counter` shows the position in the deck as n of n.
- `carousel-add` appends a blank slide.
- `carousel-duplicate` copies the current slide.
- `carousel-navigate` steps forward and backward through the deck.
- `carousel-layout` applies a named template to the current slide.
- `carousel-manager` lists the slides and selects one.
- `carousel-remove` deletes a slide.
- `carousel-preview` switches between editor, Instagram, LinkedIn, and all-pages.
- `carousel-palette` sets the deck background, text, and accent colours.
- `carousel-embed` renders the tool without the site header.

## How to get to it (user POV)

- Open `/tools` and choose the **Instagram Carousel Creator** tile.
- Open `/tools/carousel-creator` directly.
- From a chat artefact, choose **Open editor**, which lands on
  `/tools/carousel-creator?carouselId=<id>`.
- Add `?embed=1` for the headerless frame the chat embeds.

## Driving it with Playwright

Preconditions:

- Doctor passes on `http://localhost:3000`.
- No login, no business, and no database fixture. This is meant to be the cheapest
  feature in the map to prove, so use it when checking the harness itself.
- The header shows a **Login** link. That is how you confirm the session is absent.
  The auth gate covers `/app`, `/login`, and `/register` only.
- `test.setTimeout(300000)`. Two drives on this route have already run past 400
  seconds.

### PROVEN

Observed on 2026-10-04. A full drive lives at
`../evidence/carousel-creator/findings.json` with `01-initial` through `04-editor`
screenshots beside it.

- **Load the editor unauthenticated.** Run
  `page.goto('http://localhost:3000/tools/carousel-creator')` then
  `waitForHydration(page)`. The header shows a **Login** link, confirming no session.
  The auth gate covers `/app`, `/login`, and `/register` only. Set the viewport to
  1440x1000 first; the two-column editor collapses below that.
- **Read the slide counter.** Run `page.getByTestId('slide-counter').innerText()`.
  Expect `1/1` on a fresh deck.
- **Add a blank slide.** Run `page.getByTestId('btn-quick-add-blank').click()`. The
  counter reads `2/2`, and the deck lands on the new slide.
- **Navigate.** Run `page.getByTestId('btn-prev-slide').click()`. The counter reads
  `1/2`. On a fresh single-slide deck both `btn-prev-slide` and `btn-next-slide` are
  correctly disabled, and after adding a slide `btn-next-slide` is correctly disabled
  because you are on the last one. Clicking a correctly-disabled button makes
  `click()` wait for the full timeout, which is what stalled two earlier drives. Use
  the direction that is enabled, or assert `isDisabled()` first.
- **Switch the preview.** Run `page.getByTestId('preview-strip').click()`. The
  filmstrip replaces the stage. `page.getByTestId('preview-editor').click()` returns
  to the editor.
- **Handles.** The page carries 236 `data-testid` attributes and zero legacy
  `data-test` attributes. Probe with `[data-testid]`, not `[data-test]`.

## Gotchas

- **The interactive drive has never finished.** Two attempts on 2026-10-04 each ran
  past 400 seconds, and the first screenshot step produced no handles dump. A `200`
  from curl proves nothing about the editor, because curl returns while the browser
  session hangs.
- **The likeliest cause is on-demand dev compilation** of a route with heavy
  uncommitted changes. That is a hypothesis, not a measurement. An infinite loop was
  ruled out by reading the three new files, which hold no while loop and no recursive
  watcher.
- **Attributes are `data-testid`,** not `data-test`. Every handle on this page uses
  the longer form. A `[data-test="..."]` locator resolves nothing and Playwright waits
  on it until the test times out, which is the shape of the two failed attempts.
- **The stage is not fabric.js.** CarouselStage holds no fabric. Only a separate
  FabricStage does, and it appears only behind `?fabric=1`. The 2026-10-02 map claimed
  the stage was fabric.
- **Layer ids are not index-based.** They read `layer-<timestamp>-<random>` and change
  on every render, so `btn-layer-vis-layer-0` style handles are worthless. Never assert
  on a layer id.
- **The deck does not survive a reload.** Deck state is a module singleton, so
  `page.reload()` discards the whole deck. Prove persistence through the save or export
  action.
- **`?carouselId=` needs a session and fails silently.** It reads `/api/v1/carousel`
  and swallows any failure, so an anonymous visitor gets a blank deck with no error.
  Do not use that flag to prove the load.
- **`?embed=1` removes the header,** so the `Login` check is unavailable in that mode.
- **Not every tile is a template.** `slide-template-<key>` values come from the twelve
  template keys, and every one of them starts with `layer-`. There is no
  `slide-template-cta`. The nearest is `slide-template-layer-sticker-cta`, whose
  accessible name is `Layout: Sticker CTA`, not the `Layout: CTA Finale` the
  2026-10-02 map recorded.
- **Palette handles are colour inputs,** named `palette-bg`, `palette-text`, and
  `palette-accent`. There is no `palette-preset-*` handle anywhere in the repo, so the
  `palette-preset-midnight` in the 2026-10-02 map was invented.
- **Three uncommitted files and one modified component changed this route.**
  `CarouselSlideStrip.vue` at 277 lines, `CarouselSlideViewer.vue` at 288 lines, and
  `carouselPatternHtml.ts` at 17 lines were added, which is where the slide strip and
  the per-slide editor previews come from. `CarouselSection.vue` repointed **Open
  editor** to `/tools/carousel-creator?carouselId=` and gained a save button and a
  fullscreen viewer. The 2026-10-02 map predates all of it and omits both the strip and
  the previews.
- **Sharing mints a real URL.** `pill-share-carousel` points at
  `/tools/carousel/shared/:slug`. Treat that as a side effect to record and clean up
  rather than something to hammer.
